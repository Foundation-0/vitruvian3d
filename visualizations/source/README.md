# Archived initial interactive explainers

These two source fragments are preserved unchanged from the initial geometric exploration:

- `vitruvian-lattice-motion.html`: coordinated equal-length link sweeps around a fixed octahedral motif.
- `room-and-reach.html`: the distinction between a cavity and its passage openings.

They illustrate the initial geometry. They do not incorporate the later passage, rod, transition, or layer proofs, and archiving them supplies no updated proof claim.

These are HTML fragments for the original host, not standalone web pages. They require host style variables and utilities, including theme colors, typography, and native control classes. Optional host state APIs remember interaction choices. A separate wrapper would be needed for an independent browser preview.

`SHA256SUMS` records the unchanged source bytes. No private paths or raw session logs are included.
